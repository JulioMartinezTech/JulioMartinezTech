- **Temas Shopify** en Liquid sobre Online Store 2.0, con secciones configurables y soporte multiidioma
- **Integraciones con CMS headless** — configuración y despliegue de Strapi Cloud, consumo de APIs REST
- **Scripts Node.js** para automatización y carga de datos
